# Contributing

Thanks for considering a contribution.

1. Open an issue describing the bug or proposed improvement before making a large change.
2. Create a focused branch and keep the change small.
3. Install dependencies with `pip install -r requirements.txt -r requirements-dev.txt`.
4. Run the test suite with `python -m pytest -q`.
5. Submit a pull request describing the change, testing performed, and any known limitations.

Do not commit API keys, credentials, private datasets, or local environment files. Keep claims about forecast accuracy tied to reproducible out-of-sample evaluation; this project is educational and is not financial advice.
